Get your disk space back.

Ballast is a menu bar app that clears out what your developer tools leave behind, without breaking a project.

Download for macOS View on GitHub

Free · open source · macOS 14+

Memory alerts

When memory runs short, the menu bar icon changes and the menu names what's using it.

  • Command-line tools are grouped per project, like vitest · my-app.
  • Close asks first. Nothing is closed automatically.
  • macOS's own processes can't be measured, so Ballast won't blame them.
  • Uses about 28 MB and next to no CPU. Nothing is written to disk.

Knows what's in use

It reads your projects, worktrees and running processes before labelling anything.

Install

macOS 14 or later.

Download

  1. Unzip the latest release.
  2. Move Ballast.app to ~/Applications and open it.

Ballast isn't notarised. If macOS blocks it, click Open Anyway in System Settings → Privacy & Security, or run:

xattr -dr com.apple.quarantine ~/Applications/Ballast.app

After that, updates take one click.

Download latest release

Build from source

Needs Swift 6. The Command Line Tools are enough.

git clone https://github.com/linearza/ballast.git
cd ballast
make install

Builds Ballast, copies it to ~/Applications and opens it. The iPhone tools also need brew install cmake pkg-config.

On first run, pick your project folders so Ballast knows what they pin.

Private by default

  • no account
  • no analytics
  • no permissions up front

The only network calls are a daily update check and, if gh is signed in, PR status for worktrees.
