The rules, short

  • Nothing without a preview. Every path moved, every command run.
  • Checked again before acting. If a version got pinned or a database started since the scan, that step is skipped and says why.
  • Trash or gone, said per step. Files go to the Trash. Commands like brew uninstall and docker image rm delete for good.
  • Asks harder as the stakes rise. Return for routine, a click for Review, I understand for anything that can lose work.
  • Never touches your home folder, Documents, Desktop, Downloads, Library, SSH and GPG keys, Keychains or macOS's own folders.
  • Refuses outright a worktree with uncommitted changes, a running database or VM, and apps that ship with macOS.
  • Uses each tool's own cleanup: ollama rm, git worktree remove, xcrun simctl delete.
  • iPhone videos are copied to your Mac and size-checked before the original goes.
  • Everything is logged to ~/Library/Application Support/Ballast/actions.log.

Your iPhone is full too.

  • Plug in by USB. It appears once the phone is unlocked and trusted. The iPhone tools are built in.
  • Videos are moved, not deleted. Each is copied to your Mac and size-checked. The original goes only if they match.

Install.

macOS 14+. No account, no installer.

Download

  1. Get Ballast-x.y.z.zip from Releases and unzip it.
  2. Move Ballast.app to ~/Applications or /Applications.
  3. Open it. macOS blocks it the first time.

Ballast is not notarised. Either open System Settings → Privacy & Security and click Open Anyway, or run:

xattr -dr com.apple.quarantine ~/Applications/Ballast.app

Ballast checks GitHub once a day for a newer release and tells you when there is one. It never updates itself.

Download latest release

Build from source

You need Swift 6. The Command Line Tools are enough (xcode-select --install); you don't need Xcode.

git clone https://github.com/linearza/ballast.git
cd ballast
make install

This builds Ballast, copies it to ~/Applications and opens it. The iPhone tools are built on the way, which takes a few minutes the first time and needs brew install cmake pkg-config. Without them the app still builds and looks for the tools on your PATH.

To remove it again: make uninstall.

First run, Ballast asks where your projects live so it can see which versions they pin. Change the folders in Settings any time.

Asks for nothing.

  • no account
  • no analytics
  • no permissions up front

Full Disk Access is only for protected locations, and it tells you when you get there. Admin steps are never run for you; you get the exact sudo command. Network use: a daily GitHub check for a new release, and, if the GitHub CLI is signed in, whether a worktree's PR is merged.
